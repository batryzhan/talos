# AGENTS.md — Спецификация v3.0 для Codex: Реалистичная Стройка и Завод, Industrial Clean UI, 3D Assets

> **Проект:** TALOS (Target-Agent Learning & Operational System) — 3D-платформа мультиагентной робототехники на React 18+ + TypeScript + Three.js + Vite.
> **Ваша роль (Codex — Agent B):** Главный архитектор 3D-окружения, реалистичных промышленных локаций (Стройплощадка с башенным краном и Металлургический цех), физики тяжелого груза M1 и промышленного операторского интерфейса без «вайбкодинга».
> **Ваш напарник (Claude Code — Agent A):** Пересобирает робота по точным CAD-размерам goBILDA/REV, поддерживает драйвер Xbox 360 и `SwarmManager`.

## 1. Строгий анти-«вайбкодинг» в интерфейсе и графике (Anti-Vibecoding Rules)

Текущий интерфейс выглядит как шаблонный «вайбкодед» стартап (крупные цветные плашки, неоновые бирюзовые круги геймпада, эмодзи в кнопках, пустые пространства). Переделайте его в **строгий промышленный интерфейс диспетчерской SCADA / ROS Foxglove Studio**:

1. **Цветовая палитра:**
   * Фон: глубокий индустриальный антрацит `#0d1117` / `#161b22`, матовые серые панели `#21262d`.
   * Никаких кислотных неоновых градиентов, радужных обводок и размытых свечений.
   * Акценты только функциональные: тусклый зелёный `#238636` (READY/норма), янтарный `#d29922` (WARN/смещение), строгий красный `#da3633` (HOLD/FAULT).
2. **Типографика и вёрстка:**
   * Использовать `font-mono` (`ui-monospace`, `JetBrains Mono`, `Roboto Mono`) для всех чисел, матриц и логов с `tabular-nums`.
   * Плотная компоновка данных: таблицы реакций опор ($F_i$, Н), высоты ($h_i$, мм), рассогласования ($E_h$, мм), запаса ($\rho$, м), частоты кадров и пакетов (Гц).
   * Заменить эмодзи в меню на лаконичные текстовые лейблы: `[01 // STRAFER CALIBRATION]`, `[02 // HEAVY CONSTRUCTION]`, `[03 // INDUSTRIAL FACTORY]`, `[04 // BENCHMARK M0]`.
3. **Виджет геймпада Xbox 360:**
   * Убрать гигантские неоновые круги. Сделать компактный технический блок со шкалами осей стиков и индикацией активных триггеров LT/RT.

## 2. Реалистичные 3D-локации: Стройка и Индустриальный Завод (`src/platform/` & `src/missions/`)

Вместо примитивных серых столбов в пустом пространстве создайте атмосферные, детализированные индустриальные сцены (используйте скиллы `threejs-procedural-architecture`, `threejs-shadow-systems`, `threejs-procedural-materials`):

### 🏗️ Локация 1: Строительная площадка (Heavy Construction Site)
* **Архитектура сцены (как на референс-фото):**
  * Монолитный железобетонный каркас многоэтажного строящегося здания с круглыми колоннами, плитами перекрытий и защитными лесами.
  * Башенный кран из решётчатых жёлтых металлоконструкций со стрелой и противовесом.
  * Строительные бытовки, контейнеры, паллеты со стройматериалами, разгрузочная зона грузовиков.
  * Текстуры: сырой бетон с текстурой опалубки, песчано-гравийная поверхность земли со следами гусениц и колес.
* **Миссия роя:** Бригада из 8–12 тяжелых роботов TALOS заезжает под многотонную ж/б секцию пролёта со смещённым центром тяжести, поднимает её 4-колонными порталами и перемещает по стройплощадке к месту монтажа краном.

### 🏭 Локация 2: Тяжёлый металлургический / сборочный цех (Industrial Factory)
* **Архитектура сцены (как на референс-фото цеха):**
  * Промышленные мостовые краны и фермы под потолком с рельсовыми путями.
  * Индустриальное оборудование: массивные технологические печи/котлы, трубопроводы, вентиляционные шахты, стальные мостики с перилами и лестницами.
  * Атмосферное освещение: точечные промышленные светильники верхнего света, лёгкая дымка/пыль (fog), теплый отблеск технологических зон.
  * Пол: серый шлифованный промышленный бетон с желто-черной сигнальной разметкой проездов и зон разгрузки.
* **Миссия роя:** Роботы осуществляют стыковку двух тяжелых агрегатов на весу с субмиллиметровой точностью ($E_h < 1\text{ мм}$), динамическую ротацию по разряду батарей (отъезд на станцию зарядки с инкрементом `epoch`) и распределение по терминалам отгрузки.
